# 街头错位案例

## 用法

这些是原创方案示例，不是对已有影片结果的认证，也不是固定生产清单。先确定正常动作，再借案例选择一种错位关系；允许换职业、墙色或器物，不应只换背景重复同一个笑点。优先能在全景里同时看到异常与正常对照、能够通过一个小动作实现的方案。

| 类别与案例 | 正常生活基底 | 可见证据与对照 | 可执行动作与边界 |
| --- | --- | --- | --- |
| 对象：给云熨衣服 | 裁缝熨烫、顾客等待 | 小白云压在木熨衣板上，旁边晾正常衬衫 | 熨斗缓慢推一小段，云有软体积和支撑；不是云海、漂浮仙境或发光蒸汽特效。 |
| 材料：布做的加油机 | 给普通摩托加油 | 机身有帆布纤维、缝线与微塌边角，软管和摩托仍是橡胶金属 | 开场油枪已在油箱口，手保持正常加油姿态、布微动；不是充气玩具或火焰事故。 |
| 现象：搬运一片树荫 | 两人搬运、店主指位置 | 影纹有薄片般握持边缘、中央下垂，现场人物还有正常投影 | 承重走一小步；避免只有普通印花布或黑色传送门，需让物化影子与太阳下街面关系可见。 |
| 用途：修鞋摊修脚蹼 | 修补鞋底 | 正常尺寸黄色脚蹼与旧皮鞋并列 | 已握住脚蹼，压补片或拉紧一小段线；顾客坐等，不穿脚蹼奔跑。 |
| 对象：洗镜子里的车 | 洗车、顾客等候 | 有真实支架的镜子显示同一辆红车，镜外街面没有对应车 | 海绵擦过镜面，水与泡沫在玻璃上；不是电视或照片，倒影透视稳定。 |
| 对象：给石头编头发 | 理发、顾客等待 | 石头只有真实长发，没有脸和四肢，旁有梳子夹子 | 辫子已有一小段，继续交叉收紧；石头不变卡通生物或自行移动。 |
| 材料：陶瓷自行车 | 修车打气、车主扶车 | 白蓝釉面车架有硬质反光，正常轮胎、链条、皮座作对照 | 气管已接好，缓慢泵压并扶稳；单纯涂白不能说明陶瓷，车架不能软化。 |
| 现象：晾晒一小片雨 | 收晾衣服 | 一窄条局部雨落入盆，周边衣物和街面在日光下保持干燥 | 摘折一件正常衬衫，雨区保持稳定；不是全街暴雨、玻璃板或瀑布。 |
| 对象：街边称月亮 | 摊主称重、顾客看秤 | 西瓜大小的灰白坑洼球体在机械秤上，旁有普通蔬果 | 扶正后放手、秤盘轻沉回稳；不用宇宙背景，不发光漂浮。 |
| 用途：早餐摊煎黑胶唱片 | 摊主烹调、顾客端盘等 | 完整沟槽唱片在银锅中，旁有正常食物 | 锅铲轻托边缘后放回，不强求高抛；不融化、不出音符或音乐视觉特效。 |
| 规则：排队过没有墙的门 | 礼貌排队通行 | 有铰链与支撑底座的独立门框，左右可绕行，门后仍是同一街道 | 只让队首开门通过、下一人前移；无传送光效或场景切换。 |
| 形状：给方形轮胎打气 | 修车泵压、顾客坐等 | 方形外轮廓、贯通开口、真实胎纹气嘴，旁有圆胎 | 气管预先连接，缓慢压两次再按胎；方形保持，不滚动变圆。 |
| 对象：给空西装拍证件照 | 摄影师整理领口、拍摄 | 衣领上方能看见背景、袖口没有手，衣物被椅子支撑 | 扶正领子后回相机按快门；不露出假人，不长头手，不变惊悚灵体。 |
| 用途：给路面拉拉链 | 维修工处理路缝、店主扫地 | 金属齿确实连接两侧石板路缘，拉头与路缝有接触 | 只缓拉二三十厘米并停检；不是地上玩具，不掀整街、不把石材变成布。 |

## 选择检查

若删掉创意名称，画面是否仍能说明异常？若只能靠文字把白车解释为陶瓷、把普通收衣解释为雨，应补足材料或空间证据，或换成更容易在全景读懂的异常。不要靠增加第二、第三个奇观救一个不可读的第一异常。
