# 非洲街头荒诞影像风格 Skill

> 越是荒诞的想象，越需要对生活细致的体会。

作者：江珊珊。用于创作有真实生活质感、平静荒诞情绪的写实单图、独立短视频与系列画面。

## 创作方法

先建立可信的生活动作，再设计一个主要异常。通过风化柔色墙面、局部鲜色、全身环境构图、真实材料接触与克制表演，让想象自然进入日常生活。

## 使用

在支持读取 Markdown 文档的 Agent 中提供本仓库，先阅读 SKILL.md，再按任务阅读对应参考文档。媒体生成需要另行接入兼容的图像或视频工具；本仓库本身不提供生成服务。

示例请求：

> 使用这个 Skill，围绕街边修鞋构思三个平静荒诞的画面。先给出创意与画面方案，等我确认后再生成。

> 制作“给云熨衣服”的单张横向画面。保留日光旧街区、自然劳动姿态和真实接触关系，先向我展示具体方案。
